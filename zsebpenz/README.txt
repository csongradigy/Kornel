ZSEBPÉNZ KALAND

1. A gyors kipróbáláshoz nyisd meg az index.html fájlt egy böngészőben.
2. Telefonra telepíthető offline webalkalmazásként (PWA) a mappa fájljait HTTPS-es statikus tárhelyre kell feltölteni, például GitHub Pages-re.
3. Telefonon nyisd meg a HTTPS-címet, majd válaszd a „Hozzáadás a kezdőképernyőhöz” / „Alkalmazás telepítése” lehetőséget.
4. A szülői részben az első belépéskor állíts be legalább négyjegyű PIN-t.
5. Az adatokat a böngésző helyben tárolja; külön készülékek között nincs szinkronizáció. Készíts rendszeres JSON biztonsági mentést.
6. Figyelem: a PIN nem véd a böngésző fejlesztői eszközeihez hozzáférő személyek ellen. Nem pénzügyi számlakezelő rendszer.
